# 77 · Product Manager / AI Builder

A personal portfolio built with React, Vite, GSAP and WebGL.

- Website source: `website/`
- Deployment: `.github/workflows/deploy-pages.yml`
- Local development: `cd website`, `npm ci`, `npm run dev`
- Production: `npm run build`
- Production preview: `npm run preview`, then open `http://127.0.0.1:4177/77-portfolio/`

GitHub Pages deploys the built website when changes are pushed to `main`. See `website/README.md` for content, animation, typography and maintenance details. Third-party notices and font licenses are included.
