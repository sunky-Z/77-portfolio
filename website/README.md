# 77 个人站

面向初次认识 77 的访客，提供中英双语的个人介绍、职业经历、项目经过与工作方法。视觉采用黑白灰、留白和轻边框，搭配原创简笔画。英文与数字沿用 Times New Roman / Times，中文优先使用 SF Pro SC / PingFang SC；设备未安装时回退到系统中文字体，不分发 Apple 字体文件。

## 信息结构

网站采用“首页 → 分类总览 → 详细正文”的三层架构。首页保留个人简介、三张分类入口、三个重点项目及联系入口；完整经历、项目和方法分别放在分类页。HR 可以先看职业经历与教育背景；业务负责人可以进入项目正文读具体工作和交付物；陌生访客可以从简介开始。

全站有 19 个独立页面，另有未找到页面。主导航和卡片使用普通链接打开新页面，每个网址都对应构建目录中的独立 `index.html`，可直接访问、刷新、分享或在新标签中打开。页面路径相对于站点根目录：

| 层级 | 路径 | 内容 |
|---|---|---|
| 首页 | `/` | 个人简介与分类入口 |
| 分类 | `/experience/` | 职业经历与教育背景 |
| 分类 | `/projects/` | 七个项目主题 |
| 分类 | `/capabilities/` | 四个能力与方法分支 |
| 联系 | `/contact/` | 邮箱及复制入口 |
| 经历详情 | `/experience/huawei/`、`/experience/hardware/`、`/experience/current/` | 三段职业经历正文 |
| AI 专题 | `/projects/ai-ecosystem/`、`/projects/skill-ecosystem/`、`/projects/ai-commercialization/`、`/projects/international-product/` | 主动服务与任务体验、技能发现与质量治理、订阅权益、海外产品与本地化 |
| 研究与产品分析 | `/projects/energy-research/`、`/projects/hardware-research/`、`/projects/product-business/` | 能源产品研究、智能硬件研究、C 端产品分析与商业化 |
| 方法详情 | `/capabilities/research/`、`/capabilities/planning/`、`/capabilities/ai/`、`/capabilities/delivery/` | 方法、应用项目与工作范围 |

详情页通过面包屑显示“首页 / 所属分类 / 当前内容”，返回入口明确指向父分类。项目正文包括工作背景、关键工作、交付及思考；有相应材料的专题另列“关键判断”和“交付进展”，说明规则选择及设计、验收、上线或跟进状态。经历、项目与方法通过相关卡片交叉链接；页内目录仅用于定位当前正文的小节。切换语言保留当前页面及阅读位置。旧版 `#about`、`#projects`、`#strengths`、`#work/…`、`#experience/…`、`#skills/…` 等地址转换到对应新页面。

页面文案以具体工作、操作和产物为主，保留参与、负责及协作范围。AI 相关内容按四个专题展开，属于同一段 DROI 工作的不同主题。数字保留各自的对象、阶段与状态：工作范围、模板与原型覆盖、内容治理数量、多语言配置和正式服写入分别表述；不将这些数量改写为用户增长、转化提升或收入结果。C 端产品经营分析与 AI 订阅体系分别呈现，未补齐口径的留存和收益指标不进入公开文案。

文案采用短标题、重点摘要与事实正文的层级。首页突出从用户研究到 AI 产品的职业方向，卡片聚焦工作主题，正文说明职责、方法与交付。避免口语化引导、泛化口号与未经证实的成绩；中英文保持一致的职责范围。

## 源码维护

- `src/App.jsx`：首页、分类总览、联系页、三类正文和页面交互。
- `src/portfolio.js`：双语简介、概览卡片、职业入口、项目卡片和能力正文。
- `src/content.js`、`src/content.zh.js`：双语项目正文与职业经历详情。
- `src/routes.js`：页面路径、层级、静态页面清单及旧地址映射。
- `src/hooks/usePortfolioNavigation.js`：从当前网址选择页面及处理旧地址。
- `scripts/build-pages.mjs`：构建资源并为每个页面生成独立 HTML、标题和分享元数据。
- `src/i18n.js`：语言选择，首次按浏览器语言，后续记住本机选择。
- `src/styles.css`、`src/fonts.css`：黑白灰卡片与正文布局、响应式、字体和减少动态设置。
- `public/assets/sketch-*-v2.webp`：四张原创黑白线稿，900×600，总约 80KB；以通用成年男性为主角，减少面部、发丝与服装细节，不作为 77 的肖像或真实产品截图。
- `public/assets/case-skills.svg`、`case-subscription.svg`、`case-localization.svg`：三个 900×600 的代码原生概念图，分别表达分类治理、账户设备与权益关系、内容多语言适配；黑白灰线条、无可见文字，不作为实际产品截图。

页面不再引用旧的视频、WebGL 背景、磁吸或开场动效。原组件与素材保留在源码中，但不进入当前页面运行和下载路径。新版插画使用内置 imagegen 生成：纯白背景、稀疏黑线、极少黑色块面，统一短发男性主角；避免漫画式五官、细致发丝、写实解剖与大面积灰色阴影。四张主题分别为男性与机器人整理任务、男性研究员访谈、男性观察硬件、男性比较图表。文件分别为 `sketch-ai-v2.webp`、`sketch-research-v2.webp`、`sketch-hardware-v2.webp`、`sketch-growth-v2.webp`。

顶部概括图单独使用 `public/assets/hero-profile-summary-v1.webp`，不复用项目卡片封面。该图由内置 imagegen 生成，采用与项目插画一致的白底稀疏黑线风格：一位通用成年男性在统一工作台上，将用户需求卡整理为产品原型，与简化 AI 助手及交付勾选卡构成连续场景，概括用户研究、产品规划、AI 产品设计与交付。没有文字、Logo 或真实肖像，人物仅作通用示意；分享封面同步使用这张概括图。

内容依据本人确认的职业经历、原项目说明及简历整理稿；简历、周报和核对资料只作本地只读来源，不复制进公开仓库或站点。公司日期为 HUAWEI（2021.06–2024.04）、NINESTAR（2024.06–2025.04）、DROI（2025.11–至今）；学校沿用 WNU 与 YBU，联系邮箱由本人提供。私人档案源文件不进入公开仓库或站点。

## 本地预览与发布

使用 React + Vite。依赖已安装时直接运行 `npm run dev`，访问 http://127.0.0.1:5177 。`npm run build` 生成共享资源、19 个页面的独立 HTML 及 `404.html` 到 `dist/`，`npm run preview` 在 4177 端口预览。

架构调整后的核验重点为：分类卡片打开独立网址；三级页面直接访问和刷新可用；面包屑、父分类返回、浏览器前进与后退一致；中英切换保持所在页面；手机导航无横向溢出；旧地址可进入对应新页面。构建和浏览器核验结果以本次交付记录为准。

网站源码位于本仓库的 `website/`，默认生产路径为 `/77-portfolio/`。构建时也可通过 `VITE_BASE_PATH` 指定，生产预览访问 http://127.0.0.1:4177/77-portfolio/ 。

推送 `main` 后，GitHub Actions 使用 Node.js 24 安装依赖并构建，只发布 `website/dist`。网站地址为 https://sunky-z.github.io/77-portfolio/ 。

不提交本机依赖、构建产物、环境变量、运行资料或临时文件。第三方组件的历史许可保留于 `THIRD_PARTY_NOTICES.md`。
